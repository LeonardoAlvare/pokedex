# Tutorial: Creación de Cuenta en Azure for Students

## Requisitos Previos

Antes de comenzar, asegúrate de tener a la mano lo siguiente:

- Un **correo electrónico educativo válido** (ej. `@tecnocomfenalco.edu.co`).

- Documentación o acceso para la **verificación de tu estatus de estudiante**.

- Un **número de teléfono** activo para la verificación de seguridad de la cuenta.

## Paso 1: Ir al Portal de Azure for Students

1. Abre tu navegador web de preferencia.

2. Dirígete a la página oficial de [Azure for Students](https://azure.microsoft.com/es-es/free/students/).

## Paso 2: Comenzar el Registro

1. En la página principal de Azure for Students, localiza el banner central.

2. Haz clic en el botón verde que dice **"Empezar gratis"**.

## Paso 3: Iniciar Sesión

1. Al ser redirigido a la página de inicio de sesión de Microsoft, ingresa tu **correo electrónico educativo**.

2. Ingresa tu contraseña y haz clic en **"Iniciar sesión"**.

## Paso 4: Verificar Estatus de Estudiante

1. Serás redirigido a un formulario de "Academic Verification".

2. Completa el formulario con tus datos personales y académicos (nombre, correo, escuela, etc.).

3. Completa el desafío visual (CAPTCHA) para demostrar que eres humano.

4. Haz clic en el botón **"Verify academic status"** para confirmar que cumples con los requisitos.

## Paso 5: Verificar la Cuenta

1. Como medida de seguridad adicional, el sistema solicitará verificar tu identidad.

2. Ingresa tu número de teléfono para recibir un código de confirmación (vía SMS o llamada).

3. Introduce el código en el portal y espera a que el sistema procese la confirmación (_"Confirming your account..."_).

## Paso 6: Listo

Tu cuenta de **Azure for Students** ha sido creada y verificada exitosamente.
Ahora tendrás acceso al portal de _Education Overview_, donde podrás ver tus \$100 USD disponibles, explorar rutas de aprendizaje y comenzar a provisionar recursos en la nube como App Services, Bases de datos y más.
